# 图片转 PDF

## 参数

- 输出方式：全部图片合并为一个 PDF，或每张图片生成一个 PDF。
- 页面尺寸：A4（595 × 842 pt）或适配图片比例。
- 页面方向：自动、纵向、横向。
- 页边距：0–72 pt。

## 页面预览

功能页面会把所选图片按输出顺序纵向展示为 PDF 页面缩略图。预览窗口高度固定，可在窗口内独立上下滑动，因此图片数量不会持续挤压下方的 PDF 设置区域。缩略图按比例居中显示在白色页面中，并会反映页面尺寸、方向和页边距设置；用户可在预览中调整页面顺序或移除图片。

图片按列表顺序写入，每页白色背景并等比缩放到可用区域。处理过程中只保留当前页位图。合并模式下损坏图片会被跳过；只要至少有一页成功，仍会保留 PDF，并在结果页报告失败项。

默认输出目录：应用专属 `Documents/Natsuko/ImagesToPdf/<时间戳>/`。开启“保存至用户存储目录”后，合并或逐图生成的 PDF 自动保存到 `Download/Natsuko/ImagesToPdf/` 或自定义目录下的 `ImagesToPdf/`，不再增加时间戳目录；也可在处理完成页开启开关并立即补存本次结果。详见 [输出存储](output_storage.md)。
