# 图片转 PDF

## 参数

- 输出方式：全部图片合并为一个 PDF，或每张图片生成一个 PDF。
- 页面尺寸：A4（595 × 842 pt）或适配图片比例。
- 页面方向：自动、纵向、横向。
- 页边距：0–72 pt。

## 页面预览

功能页面会把所选图片按输出顺序纵向展示为 PDF 页面缩略图。预览窗口高度固定，可在窗口内独立上下滑动，因此图片数量不会持续挤压下方的 PDF 设置区域。缩略图按比例居中显示在白色页面中，并会反映页面尺寸、方向和页边距设置；用户可在预览中调整页面顺序或移除图片。

图片按列表顺序写入，每页白色背景并等比缩放到可用区域，使用完整色深解码，不透明图片不会降为 16 位色。合并模式下损坏图片会被跳过；只要至少有一页成功，仍会保留 PDF，并在结果页报告失败项。

## 内存与像素预算

系统的 `PdfDocument` 会保留每一页的像素，直到整份文件写出；处理器回收位图并不能提前释放它们。因此同一份 PDF 的全部页面共用 1.6 亿像素的解码预算（完整色深下约 640 MB）：

- 每页的像素上限为预算除以页数，且不低于 50 万像素。图片的处理尺寸（最长边 4096 px）超过上限时，解码时按比例缩小；未超过的图片保持原样。
- 页面尺寸、方向和页边距始终按图片的处理尺寸计算，预算只减少嵌入的像素，不改变版面。
- 约 12 张 1200 万像素的照片以内不受影响；100 页时每页约 160 万像素。超过 320 页后每页保持 50 万像素，总量随页数继续增长。
- 逐图生成时每份 PDF 只有一页，不缩小。

完整色深与像素预算尚未发布，记录于 [CHANGELOG 的 unstaged 条目](../CHANGELOG.md#unstaged)。

默认输出目录：应用专属 `Documents/Natsuko/ImagesToPdf/<时间戳>/`。开启“保存至用户存储目录”后，合并或逐图生成的 PDF 自动保存到 `Download/Natsuko/ImagesToPdf/` 或自定义目录下的 `ImagesToPdf/`，不再增加时间戳目录；也可在处理完成页开启开关并立即补存本次结果。详见 [输出存储](output_storage.md)。
