# PDF 转图片

## 参数与输出

- 支持一次选择多个 PDF。
- 输出格式：PNG 或 JPEG。
- 渲染倍率：1×–3×；为避免内存压力，实际结果最长边不超过 4096 px。
- JPEG 质量：60–100；PNG 使用无损编码。

每页独立输出，文件名包含输入序号、PDF 名和页码。处理一个损坏 PDF 时会继续转换同一批次的其他 PDF，并在结果页给出逐文件原因。

默认输出目录：应用专属 `Pictures/Natsuko/PdfToImages/<时间戳>/`。开启“保存至用户存储目录”后，各页成品自动保存到 `Download/Natsuko/PdfToImages/` 或自定义目录下的 `PdfToImages/`，不再增加时间戳目录；也可在处理完成页开启开关并立即补存本次结果。批量保存时显示进度，逐文件报告保存失败，已生成的图片仍可使用。详见 [输出存储](output_storage.md)。
