# 图片分割

## 概述

「图片分割」用于将单张静态图片沿横向或纵向切分为 2–20 份独立图片，便于制作多图拼排（例如 X / Twitter 多图横向或纵向衔接与间隔错位效果）。功能归入首页「图片」分类，并提供同名系统分享目标 `ImageSplitShare`（`图片分割 · Natsuko`）。

## 入口与主流程

1. 从首页点击「图片分割」打开系统单张图片选择器，选图后直接进入分割操作页；也可从其他应用分享图片到「图片分割 · Natsuko」。
2. 一次仅处理一张图片。若通过系统分享传入多张有效图片，先进入选图页由用户选择其中一张，不静默取第一张，也不自动开始处理。
3. 操作页上部固定显示**分割示意图**，在原图上按当前分割方向与份数实时绘制高对比度分割线及分段序号，支持双指缩放（最高 8 倍）、平移和双击还原。
4. 用户在操作页调整分割方向、分割份数与分割模式，可随时点击「全屏操作」放大精细调整，或点击「分割预览」查看切分后多图排列与间隔效果。
5. 点击「开始分割」后在后台以原图分辨率无损导出各张 PNG 成品，完成后进入结果页查看、分享或保存到用户存储目录；结果页提供「继续调整分割」，可返回操作页保留当前参数继续修改并再次导出。

## 功能细节

### 分割方向、份数与分割线宽度

- **分割方向**：支持**横向**（默认）与**纵向**两种方向，与「图片拼接」保持一致：
  - **横向**：沿水平方向切分为左右排列的 1..N 张图片（在原图上绘制竖向分割线）。
  - **纵向**：沿垂直方向切分为上下排列的 1..N 张图片（在原图上绘制横向分割线）。
- **分割份数**：支持 `2–20` 份（默认 `2` 份），可通过 `-` / `+` 步进按钮、数字输入框或快捷预设（2、3、4、6、8 份）调整。当图片沿当前分割方向的像素尺寸小于 20 px 时，份数上限自动收紧至该方向像素数；不足 2 px 时禁用分割与预览，并提示切换方向或重选图片。
- **分割线宽度**：默认 `0 px`（不剔除任何画面），支持通过 `-` / `+` 步进按钮或数字输入框配置（上限 `500 px`，同时保证每份成品至少保留 `1 px`）。当宽度大于 `0 px` 时：
  - 导出时将剔除每条分割线覆盖区域的像素，使多图在社交平台带间隔排布时画面线条衔接更自然；
  - 操作页及全屏的**分割示意图**按实际像素比例以半透明遮罩与双侧边界线标出被剔除的分割带，并在摘要和拖动提示中显示具体宽度与像素区间；
  - **分割预览**按实际剔除后的切片排列渲染，摘要同步展示当前分割线宽度，并支持在预览页直接通过 `-` / `+` 同步微调。

### 分割模式

- **均等分割**（默认）：扣除所有分割线宽度后，将剩余画面沿所选方向均匀切分，边界按四舍五入分配，保证各份尺寸最多相差 1 px。
- **自由分割**：每条分割线（或分割带中心）显示可拖动手柄（多条分割线时交错排布避免重叠）。用户可在操作页示意图或全屏画面中直接拖动分割线调整位置，拖动时顶部实时显示分割线像素坐标（或被剔除区间）及相邻两份尺寸；轻触或拖动选中某条分割线后，亦可在下方使用 `-10` / `-1` / `+1` / `+10` px 按钮微调，或点击「重置为均等」恢复均分。
- 分割线始终严格保持先后顺序，不会越过相邻分割线或画面边界，每份至少保留 1 px。

### 全屏操作

- 点击「全屏操作」进入沉浸式全屏编辑画面（隐藏系统状态栏与导航栏，并保留屏幕挖孔安全区）。
- **方向自适应**：横向图片（宽 > 高）自动适配手机横屏展示（`SCREEN_ORIENTATION_SENSOR_LANDSCAPE`），操作栏收窄至侧边栏以保留完整画面高度；纵向图片（高 > 宽）自动适配竖屏展示（`SCREEN_ORIENTATION_SENSOR_PORTRAIT`），操作栏位于顶部；正方形图片保持自然方向。退出全屏或离开页面时恢复默认屏幕方向并显示系统栏。
- 全屏画面支持自由拖动分割线、双指缩放（最高 8 倍）、平移、双击重置缩放，并可直接切换均等／自由模式、重置均分或跳转分割预览。

### 分割预览

- 点击「分割预览」查看所有分割成品按当前方向顺序排列后的整体效果（横向为从左到右排列，纵向为从上到下排列），支持双指缩放和平移检查局部衔接。
- **图片间隔**：支持 `0–500 px`（默认 `24 px`），可通过 `-` / `+`、数字输入或快捷预设（`0`、`12`、`24`、`48`、`96` px）精确配置。
- **背景底色**：提供白色（`#FFFFFF`）、黑色（`#000000`）、深蓝灰（`#15202B`，适配深色社交时间线）、浅灰色（`#E6E9EE`）、米色（`#F5EEE8`）、浅蓝色（`#E9EEF5`）和浅粉色（`#FFE4E8`）七种背景色。
- 间隔与背景底色仅用于模拟多图排列效果，不会写入导出的图片；分割线宽度（大于 `0 px` 时）会在预览与正式导出中同步剔除对应区域的像素，正式导出输出各张独立的裁切图片。

## 图像保真、性能与输出存储

- 预览使用最长边 2560 px 的完整色深 sRGB 解码；正式分割始终以原图完整分辨率（正确应用 EXIF 方向后的 sRGB 像素）无损导出为 PNG，不压缩画质、不引入额外留白，保留原图透明度。
- 总像素不超过 2400 万像素的原图一次性解码后按切片导出并逐张回收；超过 2400 万像素的超大图改用 `ImageDecoder` 按单张切片区域逐块解码导出，控制峰值内存占用。单张切片像素上限为 5200 万像素。
- 动态 GIF、动态 WebP 等动画图片明确报错，不静默导出第一帧。处理过程支持随时取消，取消或失败时清理本次已生成的未完成文件与空目录。
- 文件命名：`<安全化原文件名>_part_01.png` 至 `_part_20.png`（两位补零，确保按文件名排序与分割顺序一致）。
- 默认应用专属目录：`Pictures/Natsuko/ImageSplit/<时间戳>/`。开启「保存至用户存储目录」后自动保存到 `Download/Natsuko/ImageSplit/` 或自定义目录下的 `ImageSplit/`（不增加时间戳目录），沿用结果页补存与逐文件重试规则，详见 [输出存储](output_storage.md)。

## 验证覆盖

- JVM 单元测试（`ImageSplitGeometryTest`）：均等分割横向／纵向 2–20 份无缝拼接与对称取整、自由分割单调约束、拖动与逐像素微调边界、极小尺寸限制、预览布局间隔与缩放、横竖图全屏方向判定及分割线命中检测。
- 设备与工作流测试（`ImageSplitWorkflowTest`、`ShareImportParserTest`、`FeatureOrderTest`、`LocalizationResourcesTest`）：首页入口、单图选择与分享导入、多图分享选图、无效／损坏／动画图片报错、横向与纵向 2–20 份像素级无损导出验证、自由分割导出与重置、全屏方向切换与恢复、分割预览间隔与底色交互、用户目录保存及五语言资源完整性。
