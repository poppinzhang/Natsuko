# 首页功能排序

## 操作方式

首页以两列等高网格直接展示所有功能卡片，卡片横向与纵向间距收窄为 `8dp`，每张卡片保留图标、所属分类、标题与简介。长按卡片任意位置后可在网格中横向、纵向或跨行拖动，将常用功能移到前面，也可跨分类调整位置。

拖动时当前卡片突出显示并跟随手指，其他卡片随目标位置调整排列。当页面内容超出可视高度时，将手指移到网格顶部或底部边缘可自动滚动，便于移动到当前屏幕之外的位置。松手后完成排序并自动保存；手势被取消时恢复本次拖动前的顺序。

普通点击仍进入对应功能。排序不需要进入设置或单独开启编辑模式；首页的设置、处理成功提示、存储说明和关于入口横跨两列展示且不参与排序。

使用 TalkBack 时，可通过功能卡片的自定义「向前移动」「向后移动」操作调整顺序；第一项不提供向前移动，最后一项不提供向后移动。

## 顺序保存

- 初次使用沿用已有首页的默认功能顺序。
- 完成拖动或无障碍移动后，顺序保存到本机，应用重启、活动重建及语言切换后保留。
- 使用稳定的功能标识保存顺序，不依赖翻译后的标题或枚举下标。
- 读取时忽略未知或重复标识，保留有效功能的相对顺序；缺少的功能按默认顺序追加到末尾，应用升级新增功能时不会重置用户排列。
- 首页顺序不改变功能处理流程或 Android 系统分享目标。

## 验证重点

- 首页以两列等高网格展示全部功能卡片，列间距与行间距为 `8dp`。
- 长按后在同列、同行及跨分类位置间拖动，松手后的排列与目标一致。
- 在较矮视口中拖动靠近网格上下边缘时持续自动滚动，能把功能移到首位或末位。
- 普通点击正常打开功能，普通滑动仍滚动页面，长按拖动不会误触打开功能。
- 取消手势恢复原顺序，完成手势后重建页面或重新启动应用仍保留新顺序。
- TalkBack 向前移动、向后移动与拖动得到相同的保存结果，首尾边界正确。
- 无记录、未知标识、重复标识及新增功能均可得到完整、无重复且确定的功能列表。
