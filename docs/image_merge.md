# 图片拼接

## 行为

- 可一次选择最多 100 张系统图片选择器支持的图片。
- 添加图片后展示整体拼接预览。画布按最终输出的宽高比缩放到预览区域，完整显示所有图片，不裁切、不拉伸，也不添加图片之间的卡片间距或圆角。
- 预览与输出共用布局计算：横向单行、纵向单列及自动网格的位置、相对尺寸、居中留白一致；切换方向或填充色会立即更新预览。
- 轻触图片即可选中，长按并拖到目标位置可调整输出顺序。预览下方显示选中图片的序号和文件名，并提供前移、后移、删除操作；图片很多或过长时，也可用“上一张 / 下一张”选择较小的图片。
- 支持纵向、横向和自动网格拼接。网格按接近平方的列数从左到右、从上到下排列，4 张图片输出为 2×2，9 张图片输出为 3×3。
- 所有输入保持原始宽高比。非拼接轴尺寸不一致时，小图居中，空余区域使用所选颜色填充。
- 网格使用等大的正方形单元；图片在单元内等比缩放并居中，未占满的区域和最后一行的空单元使用所选颜色填充。
- 当前提供白、黑、米色、蓝灰和粉色五种确定性颜色。
- 输出为无损 PNG，文件名为 `merged.png`。

## 大图策略与失败

单图解码最长边限制为 4096 px；最终图片最长边限制为 8192 px，且不超过 4000 万像素。超限时所有输入按同一比例缩小。无法读取的单张图片会记录为失败；只要仍有有效输入，就继续生成结果。

正式处理先只读取每张图片的文件头取得尺寸并计算布局，再逐张按它在成品中的显示尺寸解码、绘制并立即释放。内存占用为成品画布加一张输入，不随图片数量增长；成品被整体缩小时，各图直接解码为缩小后的尺寸。网格中被放大的小图仍按原尺寸解码，由画布放大。写入成品的像素使用完整色深解码，不透明图片不会降为 16 位色，渐变不出现色带；只有配置页的预览缩略图使用省内存的解码策略。文件头完好但像素数据损坏的图片同样记为失败并退出布局，其余图片重新排布，成品中不留空位。逐张解码与完整色深自 1.3.5 起提供，记录于 [CHANGELOG 的 1.3.5 条目](../CHANGELOG.md#135)。

预览在后台读取完整图片并缩小至最长边 512 px，布局使用与正式解码一致的 4096 px 限制后的尺寸，避免不同分辨率图片被误显示为同样大小。预览加载期间显示进度；无法解码的图片会在预览中跳过并提示，仍可通过下方选择器移除，正式处理时继续提供逐文件失败报告。

默认输出目录：应用专属 `Pictures/Natsuko/ImageMerge/<时间戳>/`。开启“保存至用户存储目录”后，成品自动保存到 `Download/Natsuko/ImageMerge/` 或自定义目录下的 `ImageMerge/`，不再增加时间戳目录；也可在处理完成页开启开关并立即补存本次结果。详见 [输出存储](output_storage.md)。
