# 国际化与语言设置

日文支持自 1.3.2 起提供，记录于 [CHANGELOG 的 1.3.2 条目](../CHANGELOG.md#132)。日文与英文、简体中文、繁体中文、韩语同为长期支持语言，后续新增或修改功能必须同步维护这五种语言。

## 用户操作

首页打开「设置」，点击「语言」，选择：

- **跟随系统**：默认选项，使用系统的受支持语言；没有受支持语言时显示英文。
- **简体中文**：固定使用简体中文，兼容已有的中文语言选择。
- **繁體中文**：固定使用繁体中文。
- **한국어**：固定使用韩语。
- **日本語**：固定使用日文。
- **English**：固定使用英文。

选择后立即刷新界面，无需手动重新启动。语言选择由 Android 持久保存，重新打开应用后仍有效；也可在 Android 系统设置中修改 Natsuko 的应用语言，两处使用同一份设置。重新选择「跟随系统」清除手动语言覆盖，后续系统语言变化自动生效。

切换语言保留当前页面、已导入文件、处理参数和本次结果。处理进度、错误、成功消息和结果说明在显示时按当前语言解析。文件名、用户指定的目录名、推文内容、品牌名与许可证原文保留其原始内容。

## 实现约定

- 仅使用 Android 16+ 原生 `LocaleManager.applicationLocales`；空语言列表表示跟随系统，不额外保存另一套偏好。
- `res/xml/locale_config.xml` 声明英文（`en`）、简体中文（保留原有 `zh` 标记）、繁体中文（`zh-Hant`）、韩语（`ko`）和日文（`ja`），默认语言为英文。英文资源位于 `res/values/`，简体中文位于 `res/values-zh/`，繁体中文位于 `res/values-b+zh+Hant/`，韩语位于 `res/values-ko/`，日文位于 `res/values-ja/`；五份文案独立维护。
- 跟随系统时，`zh-CN`、`zh-SG`、`zh-Hans` 等使用简体中文，`zh-TW`、`zh-HK`、`zh-MO`、`zh-Hant` 等使用繁体中文，`ko`、`ko-KR` 等使用韩语，`ja`、`ja-JP` 等使用日文。读取系统应用语言选择时优先识别中文的显式文字标记，没有文字标记时再按地区区分简繁。构建不再复制简体文案作为繁体资源。
- Gradle 只保留受支持的语言资源，避免依赖库的其他翻译导致界面混杂；关闭 AAB 的语言拆分，确保五种语言均随安装包提供，切换无需下载。
- Compose 静态文案使用 `stringResource` / `pluralStringResource`。跨配置变化保留的消息使用 `UiText` 保存资源及参数，渲染时解析，避免在 ViewModel 或后台处理器提前固定语言。
- 处理器使用携带 `UiText` 的异常报告已知错误；底层未知异常显示对应操作的本地化失败提示。文件路径、MIME 类型、网络协议及 FFmpeg 参数不参与翻译。
- 新增或修改文案时必须同时维护英文、简体中文、繁体中文、韩语和日文资源，覆盖功能入口、配置、进度、错误、结果、设置、关于、无障碍说明及系统分享目标。整句使用位置占位符并保持参数位置和类型；数量使用复数资源，日文只需 `other` 分支；显示用的数值按当前语言格式化，写入文件名及处理命令的值保持稳定格式。语言名称固定显示各语言的自称（日文为「日本語」），便于在任何界面语言下识别。
- Android 按语言列表及资源匹配规则选择翻译；不支持的系统语言使用英文默认资源。系统分享面板的入口名称同样提供五种语言，其展示与刷新由系统管理。

## 验证

资源测试检查五种语言的资源完整性及格式参数匹配，语言映射测试覆盖简繁文字标记、中文地区、韩语及 `ja` / `ja-JP`。语言资源 XML 也作为 Gradle 测试输入，仅修改译文时同样重新执行资源测试。Android 仪器测试覆盖语言资源与英文回退、中文和日文区域语言、五种语言即时切换、返回跟随系统、系统应用语言同步和活动重建时的工作流保留，并检查日文分享入口、错误和数量文案。既有导入、分享导入、自动处理和无效输入测试使用资源断言，不依赖测试设备默认语言。

运行 `./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest`；具备 Android 16 设备时运行 `./gradlew connectedDebugAndroidTest`。

原生 API 约定见 [Android 应用语言指南](https://developer.android.com/guide/topics/resources/app-languages)。
