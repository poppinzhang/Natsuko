# 外观与颜色模式

## 入口与选项

从首页进入「设置」，在「外观」中的「颜色模式」选择：

- **跟随系统**：默认选项，根据 Android 当前的浅色或深色设置显示界面；系统模式变化后应用同步更新。
- **浅色（Light）**：始终使用浅色界面，不受系统颜色模式影响。
- **深色（Dark）**：始终使用深色界面，不受系统颜色模式影响。

点击任一选项后立即生效，无需保存或重启应用；当前选项以单选状态标记。选择会保存在本机，下次启动仍然使用；随时可以回到设置中切换或恢复「跟随系统」。

## 应用范围

颜色模式统一应用于首页、设置、功能配置、处理进度、处理结果、关于和开源许可页面，以及应用窗口中的状态栏与导航栏图标。从 Android 分享目标进入的处理流程使用同一偏好。

图片和视频内容、PDF 白色纸张预览、拼接填充色及生成文件的颜色由原始内容和处理参数决定。外观设置不会改变成品颜色或处理规则，也不改变应用图标的原始画面。

## 实现边界

颜色偏好与文件处理状态独立保存。应用统一解析「跟随系统 / 浅色 / 深色」为当前实际模式，再由共享主题提供 Material 3 颜色；页面使用主题颜色绘制背景、文字和交互控件。缺失或无法识别的偏好回退到「跟随系统」。

## 验证重点

- 初次启动默认跟随系统，在系统浅色和深色下显示对应界面。
- 从设置切换浅色、深色与跟随系统时立即更新，选中状态与实际外观一致。
- 指定浅色或深色后，系统模式变化不会覆盖用户选择；恢复跟随系统后再次同步。
- 活动重建和应用重新启动后保留偏好；分享导入使用同一模式。
- 两种模式下主要页面、文字和系统栏图标保持可读，内容预览与成品颜色保持原处理含义。
